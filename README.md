# Bextudio — Independent Website

نسخهٔ مستقل Bextudio با React، TypeScript، Vite و سرور Node.js ساخته شده است. صفحات، تصاویر، ویدئوها، فونت‌ها، دیزاین سیستم و ترجمه‌ها در همین پوشه قرار دارند. برای اجرای سایت به Framer یا MCP نیاز ندارید.

## اجرای سریع

Node.js نسخهٔ 22.13 یا جدیدتر لازم است. روی این کامپیوتر وابستگی‌ها و خروجی build آماده‌اند.

```powershell
cd "C:\Users\p.hemati\Documents\Codex\2026-10-04\use-framer-developer-skill-to-build-2\outputs\Bextudio"
npm start
```

سایت: http://127.0.0.1:5174 — پنل: http://127.0.0.1:5174/admin — دیزاین سیستم داخل پنل: http://127.0.0.1:5174/admin?section=design-system

برای اجرا از طریق فایل، `Start-Bextudio.ps1` را در PowerShell اجرا کنید. اگر پورت 5174 در استفاده باشد، ابتدا سرور قبلی را در همان ترمینال با Ctrl+C متوقف کنید.

## زبان‌ها

| زبان | صفحهٔ اصلی | نمونهٔ خدمات | جهت |
|---|---|---|---|
| English | `/` | `/services` | LTR |
| فارسی | `/fa` | `/fa/services` | RTL |
| العربية | `/ar` | `/ar/services` | RTL |
| Türkçe | `/tr` | `/tr/services` | LTR |

انتخاب‌گر زبان در منوی سایت، صفحهٔ معادل را باز می‌کند. زبان در URL ذخیره می‌شود؛ لینک مستقیم و بازگشت مرورگر هم آن را حفظ می‌کنند. مسیر `/en` نیز انگلیسی را نمایش می‌دهد؛ آدرس اصلی انگلیسی بدون پیشوند است. پنل ادمین و کتابخانهٔ دیزاین سیستم انگلیسی‌اند.

ترجمهٔ اولیهٔ محتوای موجود، فرم‌ها و مقاله‌ها آماده است. در پنل `Translations` می‌توانید آن را ویرایش کنید. اگر متن انگلیسی تازه‌ای بسازید، ترجمهٔ آن را برای سه زبان دیگر وارد کنید؛ متن فاقد ترجمه به انگلیسی نمایش داده می‌شود. نوشته‌ها و نتایج تولیدشده توسط کاربران یا سرویس‌های AI به‌صورت خودکار ترجمه نمی‌شوند.

## ورود به پنل

نام کاربری اولیه `admin@bextudio.local` است. رمز در فایل محلی `.env`، مقابل `ADMIN_PASSWORD` قرار دارد؛ رمز در کد مرورگر ذخیره نشده است.

در پنل انگلیسی می‌توانید متن صفحه‌ها، مقاله‌ها، ترجمه‌ها، توکن‌های طراحی، تصاویر، منو و نمایش صفحه‌ها را تغییر دهید، پیام‌ها و ایمیل‌های خبرنامه را ببینید، پشتیبان JSON بگیرید و نسخهٔ قبلی را بازیابی کنید. دکمهٔ `Save changes` تغییرها را ثبت می‌کند.

بخش `Design system` شامل تب `Component library` برای نمایش رنگ‌ها، تایپوگرافی و کامپوننت‌های تعاملی، و تب `Design tokens` برای ویرایش استایل‌های مشترک است. تغییرات توکن‌ها را پیش از ذخیره در کتابخانه ببینید و سپس با `Save changes` روی سایت اعمال کنید. انتخاب‌گر رنگ کتابخانه صرفاً پیش‌نمایش موقت است. نسخهٔ مستقل کتابخانه نیز در `/design-system` در دسترس است.

## توسعه و بررسی

```powershell
npm run dev
```

این دستور سرور API روی 5174 و رابط توسعه روی 5173 را اجرا می‌کند. برای build و بررسی:

```powershell
npm run build
npm test
```

برای اجرا پس از دریافت سورس از گیت‌هاب، در پوشهٔ پروژه این دستورها را اجرا کنید:

```powershell
npm ci
Copy-Item .env.example .env
# Set ADMIN_PASSWORD and any required service keys in .env.
npm run build
npm start
```

فایل `.env`، دیتابیس و آپلودهای محلی `server/data`، وابستگی‌های `node_modules` و خروجی `dist` در گیت‌هاب قرار نمی‌گیرند. رمز پنل و کلیدهای سرویس‌ها را روی هر رایانه تنظیم کنید. برای انتقال محتوای ویرایش‌شدهٔ پنل، جداگانه از پشتیبان JSON پنل و پوشهٔ داده‌ها استفاده کنید. `npm run preview` فقط رابط ایستا را اجرا می‌کند؛ برای پنل و ذخیره‌سازی، از `npm start` یا `npm run dev` استفاده کنید.

## محل فایل‌ها

| محل | کاربرد |
|---|---|
| `src/pages` و `src/styles` | چیدمان و استایل صفحات منتقل‌شده |
| `src/components` | منو، فرم، ویدئو، رفتارهای ریسپانسیو و کامپوننت‌های مشترک |
| `src/agents` | رابط پنج ابزار AI منتقل‌شده از کد اصلی |
| `src/content` | مقاله‌ها، متن‌های قابل‌ویرایش و اتصال محتوا |
| `src/i18n` | ترجمه‌ها، مسیر زبان‌ها، RTL و فونت زبان‌ها |
| `src/design-system` | 112 توکن، نقش‌های تایپوگرافی و کامپوننت‌های قابل‌استفادهٔ مجدد |
| `src/admin` | رابط انگلیسی مدیریت سایت |
| `server` | API، نشست‌ها، فرم‌ها، پنل و دیتابیس SQLite |
| `public/assets` | 155 فایل اصلی محلی |
| `public/fonts` | فونت فارسی Estedad و عربی IBM Plex Sans Arabic همراه با فایل‌های مجوز و فونت جایگزین |
| `server/data` | دیتابیس، تاریخچه و تصاویر بارگذاری‌شده |
| `dist` | خروجی آمادهٔ اجرا |

تغییر محتوا در پنل فوراً ذخیره می‌شود و build تازه لازم ندارد. تغییر فایل‌های کد، توکن پایه یا ترجمهٔ پایه به build و سپس شروع دوبارهٔ سرور نیاز دارد.

## موارد متصل به سرویس بیرونی

لینک داشبورد اصلی به سرویس موجود Bextudio می‌رود؛ اپلیکیشن پشت آن لینک، بخشی از پروژهٔ Framer نبود. پنج رابط AI منتقل شده‌اند، اما تولید واقعی به سرویس‌های قبلی Helio و برای Digital Twin به کلید OpenRouter نیاز دارد. کلیدها و رمز دسترسی عامل‌ها در `.env` سرور تنظیم می‌شوند. چهار عامل Avatar، Detail Design، Secure Chat و BexLogix در منبع فقط صفحات معرفی داشتند؛ سیستم اجرایی جدیدی برای آن‌ها ادعا نشده است. پلن‌ها و دکمه‌های شروع حفظ شده‌اند؛ پرداخت بانکی پیاده‌سازی نشده است.

صفحهٔ پیش‌نویس `/form` در منبع خالی بود و خالی حفظ شده است. `/test` صفحهٔ مرجع اصلی است. پیش‌نویس‌های Agent Store و Pricing به مسیرهای محلی تبدیل شده‌اند.
